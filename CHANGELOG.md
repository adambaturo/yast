# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-13

### Added

- Initial release of the Rust CLI for parallel, content-based directory comparison,
  duplicate detection, and safe synchronization.
- Dry-run-first copying, content hash selection, filtering, and JSON/CSV reports.
- Linux, macOS, and Windows release archives with checksums and build provenance.
